# 인위적 드롭 ablation — Phase 5 (main_lab, both 카메라)

- 런: `sequences/mainlab_both_{1..5}` (기준, forced 0), `mainlab_both_drop20_{1..5}` (forced_drop_ratio 0.2), `mainlab_both_drop50_{1..5}` (0.5). 15런 모두 complete (06:57~07:34).
- 인위 드롭 방식: 프레임 선택 시 (µs 타임스탬프, 카메라, seed) 해시 < ratio이면 큐에서 지우고 `dropped_forced`로 셈. seed = 회차 번호라 **런마다 다른 프레임 집합**이 지워진다(카메라별 독립, 시간상 균일).
  기본값 0.0이면 동작 변화 없음 (`common.forced_drop_ratio`, `common.forced_drop_seed`).
- 스크립트: `scripts/analyze_drop_ablation.py` → `results/drop_ablation/{auto_tables.md, metrics.json, ablation.png, drop_composition.png}`
- 가로축 = **실제 총 드롭률**(자연 old/stale/overflow + 인위, img_stats csv, 카메라 평균). 세로축 = main_lab 주 지표(루프 자기 일관성) + 5회 편차.
  시작~끝 위치 차이는 bag이 2회차 도중 끝나서 drift가 아니므로 참고 열로만 둔다.

- 인위 드롭 런의 갈라짐은 **Phase 3에서 찾은 같은 두 시각/위치(T≈62 s, T≈155 s, 긴 복도 북쪽 끝 −20.7, 27.6 근처)**에 몰린다.
  즉 드롭은 오차를 고르게 쌓기보다, 원래 민감한 지점에서 **갈라질 확률을 높인다**(drop50은 5/5가 62 s 근처에서 갈라짐, drop20은 2/5, 기준은 0/5).

## 3. 해석과 한계

1. **"드롭률이 높아지면 정확도/일관성이 나빠진다"는 인위 드롭 실험에서 지지된다** (단조 증가, p < 0.01). 이 실험은 드롭률만 바꾸는 개입이라 Phase 3/4의 관찰 상관보다 인과 해석에 가깝다.
2. 하지만 **자연 드롭 21%가 현재 오차의 주원인이라는 뜻은 아니다.** 기준 both는 이미 21% 드롭 상태에서 겹침 p90 0.6 m로 4 조건 중 가장 좋고,
   +12.8 %p(33.9%)부터 확연히 나빠진다. 자연 드롭을 0으로 줄였을 때의 효과는 이 실험으로 알 수 없다(외삽 불가; 재생 속도 0.5배 등으로 자연 드롭을 줄이는 실험 필요).
3. 인위 드롭과 자연 드롭은 성질이 다르다:
   - 인위 드롭은 시간상 균일, 자연 드롭은 140 s 이후에 몰림(≈10% → ≈60%). 62 s 지점 갈라짐은 자연 드롭이 적은 구간이라 기준 런에서는 드물다.
   - 인위 드롭이 늘면 처리할 프레임이 줄어 **자연 드롭이 줄어든다**(21.1 → 17.7 → 15.8%). 총 드롭률은 파라미터만큼 늘지 않는다(+20 → +12.8 %p, +50 → +36.4 %p).
   - 드롭 이유 구성: `drop_composition.png`.
4. z 최대 이탈은 드롭이 늘수록 오히려 줄었다(1.16 → 0.77 → 0.61 m, 유의하지 않음). 주된 오차는 수평(복도 길이 방향 늘어남/줄어듦)이다.
5. 인위 드롭 런의 seed가 회차별로 다르므로 5회 편차에는 "드롭 집합 차이"와 "계산 비결정성"이 섞여 있다. 둘을 분리하려면 같은 seed로 5회 반복이 필요(다음 실험 후보).

## 4. 갱신 (09:20) — 기준 both를 10회로 늘린 결과

로깅 on/off 확인용으로 mainlab both 6~10을 추가 실행했다(08:30~09:07, `scripts/run_extra2.sh`). 그 결과 **처음 5회 기준 런이 좋은 쪽으로 치우쳐 있었다**
(겹침 p90 중앙값 1~5회 0.42 m vs 6~10회 1.99 m; 6~10회: 4.07, 0.37, 1.99, 1.25, 3.27). `analyze_drop_ablation.py`는 완료된 both 런을 모두 쓰므로 표가 바뀌었다:

| 조건 | n | 실제 총 드롭률 | 겹침 p90 [m] | 5회 편차 RMS [m] | 기준 평균 궤적까지 RMS [m] |
|---|---|---|---|---|---|
| both | **10** | 20.7 ± 0.9 % | 1.40 ± 1.26 | 1.77 | 1.77 ± 1.42 |
| both_drop20 | 5 | 33.9 ± 1.1 % | 3.57 ± 2.77 | 2.67 | 2.66 ± 2.46 |
| both_drop50 | 5 | 57.5 ± 0.7 % | 8.62 ± 5.73 (n=4, 1런 루프 실패) | 9.38 | 14.1 ± 10.4 |

추세 검정 (20런):
- 겹침 p90: ρ = 0.43, p = 0.067 (루프 실패 런 제외). 루프 실패 런을 최악 순위로 넣으면 ρ = 0.48, p = 0.031 / τ = 0.34, p = 0.040.
- 편차 RMS: ρ = 0.60, p = 0.005. 기준 평균까지 RMS: ρ = 0.72, p < 0.001. 셋 다 그룹 평균은 단조 증가.
- 주의: 기준 평균까지 RMS는 both 런이 자기 자신이 들어간 평균과 비교되므로 both 쪽에 약간 유리하다.

**수정된 해석**: 드롭률 증가 → 일관성 악화는 여전히 지지되지만 강도가 낮아졌다. drop50(실제 58%)은 분명히 나쁘다.
drop20(실제 34%)은 기준 10회의 퍼짐(0.37~4.07 m) 안에 상당 부분 겹쳐 **+13 %p 수준의 효과는 n=5로는 확실하지 않다**.
위 1~3절의 수치(기준 n=5)는 기록으로 남기되 이 절이 우선한다.

또한 140 s 이후 자연 드롭 급증은 bag 내용이 아니라 **재생 시작 후 경과 시간**에 묶인 실행 환경 현상으로 확인됐다(`results/offset_test.txt`, SUMMARY 4절).
